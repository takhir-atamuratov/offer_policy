# offer_policy

Публичная оферта и политика конфиденциальности для приложений такси (HTML, GitHub Pages).

Имена файлов: `<для кого>-<документ>-<язык>.html`

- для кого: `client` (клиент), `driver` (водитель)
- документ: `public-offer` (публичная оферта), `privacy-policy` (политика конфиденциальности)
- язык: `uz`, `qr`, `ru`, `en`

Переключателя языков на странице нет: язык выбирает приложение.

В админке («Параметр клиентской программы» / «Параметр водительской программы») ставится ссылка на один
язык, например `.../client-public-offer-ru.html`. Приложение само меняет окончание `-ru` на язык пользователя.
Поэтому у каждого документа должны быть все четыре языка с теми же именами.

Своя компания: можно сделать папку (например `1066/`) с такими же именами файлов и дать ссылку на неё.
К ссылке можно добавить `?company=Такси%201066` — название подставится в текст.
